## 設計

- バックエンドAPI(`GET /api/targets/:id/incidents`)は既に実装済み(Phase1時点)なので変更不要。
- SS-019で作った詳細モーダルに「障害履歴」テーブルを追加。
  - `started_at`/`recovered_at`/`duration_sec`/`reason`を表示。期間タブとは独立(直近20件の履歴ログ)。
  - `openDetail()`内で`loadIncidentHistory(targetId)`を呼び出し、モーダルを開くたびに読み込む。

## 副次的に発見・修正したバグ

- SS-020で追加した`#detail-title-changed-badge`(hidden属性で表示切替する想定)が、
  `.badge-changed { display: inline-flex }`に上書きされて常に表示されてしまっていた。
  SS-019で見つけた`.modal-overlay`と同種の問題。`.badge-changed[hidden] { display: none; }`を追加して解消。
  (行タグ内の`.badge-changed`はDOM追加/削除で出し分けているため影響なし)
