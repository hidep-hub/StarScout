# SS-012 実装計画・進捗メモ

対象: Electronアプリのパッケージング(StarScout.exe化・アイコン設定)

## 設計

- `packages/tray`に`electron-builder`(devDependency)を追加。`electron`は`electron-builder`が
  「exact versionが必要」と要求するため`^44.0.0`→`44.2.0`(exact)に変更。
- アイコン: `docs/10_images/starscout-banner.png`からロゴマーク部分(左上117x117)をPythonのPillowで
  切り出し・256pxへリサイズ後、多重解像度(16/24/32/48/64/128/256px)の`.ico`として
  `packages/tray/assets/icon.ico`に生成(`build/`はリポジトリの.gitignore対象なので`assets/`を使用)。
- `package.json`の`build`フィールド: `productName: "StarScout"`, `appId: "com.starscout.tray"`
  (main.jsの`app.setAppUserModelId`と同じ値で統一), `win.target: ["portable"]`
  (インストーラ不要でそのまま実行できる単一exeが「お手軽」方針に合うため)。
  `description`/`author`もpackage.jsonに追記(electron-builderの警告解消、CompanyName既定値の是正)。
- **重要な副次対応**: パッケージ版は`app.asar`が読み取り専用のため、`config.js`の
  `writeFileSync`によるconfig.json自動生成が失敗しクラッシュする問題を発見。
  `main.js`で`app.isPackaged`を見て、パッケージ時は`app.getPath('userData')`
  (`%APPDATA%\StarScout\config.json`)、開発時は従来通り`packages/tray/data/config.json`に
  切り替えるよう修正。
