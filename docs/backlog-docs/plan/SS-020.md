## 設計

- DBマイグレーション `002_content_checks.sql` 追加
  - `targets.keyword`(TEXT, 任意) — 本文に含まれるべき文字列
  - `target_state.last_page_title` / `target_state.title_changed_at`
- `src/monitor/pageTitle.js` に `extractPageTitle(html)` を切り出し、
  registration時(targets.js)とperiodic check時(httpChecker.js)で共用(重複コード解消)
- `httpChecker.checkTarget`: `success && (keywordがある || initial_page_titleが設定済み)` の場合のみ`response.text()`を読む
  (不要なtargetにまで本文読み取りコストをかけない)。keyword指定時、本文に含まれなければ`success=false, error='Keyword Not Found'`
- `monitor/engine.js`: `checkResult.pageTitle`を`target_state.last_page_title`に反映。
  `initial_page_title`と異なればtitle_changed_atをセットして`title-changed`イベントをemit(初回のみ、元に戻ったら解除)
- フロント: 登録/編集フォームにKeyword入力欄を追加。監視対象一覧の名前列に「タイトル変更」バッジ。
  詳細モーダル(SS-019で作成)に「初期タイトル/現在のタイトル/変更バッジ/Keyword一致状況」セクションを追加
